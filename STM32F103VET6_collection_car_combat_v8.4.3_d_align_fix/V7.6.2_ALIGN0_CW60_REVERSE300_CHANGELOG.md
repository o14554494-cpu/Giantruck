# V7.6.2 初始方向对齐 + 双轮顺时针 60°卸货修订

## 新卸货转向流程

1. 黑色区域达到 40%并连续确认 3 个新视觉帧。
2. 左右轮沿确认黑区时的航向同时后退 80 mm。
3. 两个车轮反向差速转动，使用 IMU PID 对齐上电时保存的初始 0°方向。
4. 对齐后继续使用两个车轮原地差速，顺时针旋转 60°。
5. 双轮倒车进入卸货区；双轮编码器均达到 300 mm、后方超声连续两次 ≤120 mm或倒车满 10 s，任一条件满足即启动舵机开仓和车体抖动卸货。

## 关键变化

- 删除单左轮逆时针 210°转向状态。
- 新增 `UNLOAD_ALIGN_INITIAL` 和 `UNLOAD_TURN_CW60` 两个状态。
- 两个转向步骤均调用原有 IMU 航向 PID，实际轮速命令为一轮正转、另一轮反转。
- 80 mm预退、300 mm倒车、后超声和10 s兜底以及舵机卸货逻辑保持不变。

## 主要蓝牙反馈

```text
BLACK >=40% CONFIRMED: BACKUP 80MM, ALIGN INITIAL, THEN CW60
PRE-TURN BACKUP 80MM COMPLETE: TWO-WHEEL IMU ALIGN INITIAL START
IMU INITIAL HEADING LOCKED: TWO-WHEEL CW60 START
IMU TWO-WHEEL CW TURN VERIFIED=60000 mdeg (60 TARGET): REVERSE INTO BLACK ZONE
UNLOAD REVERSE 300MM COMPLETE: HATCH/ SHAKE START
```
