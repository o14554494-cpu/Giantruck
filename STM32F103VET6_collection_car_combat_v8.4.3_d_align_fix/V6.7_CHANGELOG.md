# v6.7 最终扫描归零复核与倒车IMU保持状态

启动标记：`FW=v6.7+FINAL_ZERO_REVERSE_IMU_HOLD`

## 相对v6.6的修改

1. 六个60度扫描步骤结束后，不立即进入RETURN_ORIGIN。
2. 第六步仍以扫描起始航向为0度目标；最后一次观察结束后，再独立检查一次当前航向。
3. 如果停车观察期间发生惯性滑移或外界碰动，IMU PID会重新把车头转回扫描0度。
4. 只有在0度误差不超过约2度并连续稳定180 ms后，才输出 `GREEDY SCAN FINAL ZERO VERIFIED` 并进入RETURN_ORIGIN。
5. RETURN和UNLOAD倒车继续每20 ms根据IMU航向误差修正左右轮速度。Coverage状态新增 `REVERSE_IMU=HOLD/OFF`，便于蓝牙确认是否正在执行倒车航向保持。
6. IMU在扫描或倒车中失联时维持安全停车，不使用编码器角度替代。

## 蓝牙预期输出

```text
GREEDY SCAN IMU PID STEP=6/6 LOCKED ZERO_RESTORED
GREEDY SCAN FINAL ZERO REALIGN START
GREEDY SCAN FINAL ZERO VERIFIED: ERROR<=2DEG STABLE=180MS
GREEDY SCAN EMPTY: RETURN_ORIGIN START
```

```text
COVERAGE PHASE=RETURN_REVERSE_Y_150 ... REVERSE_IMU=HOLD
```
