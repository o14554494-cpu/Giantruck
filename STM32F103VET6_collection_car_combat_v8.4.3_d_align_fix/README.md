# collection_car v8.2 对抗赛编码器碰撞恢复版

这是基于 v7.6.2 双 IMU 参考工程生成的对抗赛工程。上电后比赛计时器和 IMU 初始航向采集立即独立运行，但车轮、前刷和舱门保持安全待机；只有收到蓝牙 `C` 或 `Q` 后才进入 Greedy 收集。

完整流程、蓝牙命令、故障恢复与调试方法见 `COMBAT_V8_GUIDE.md`。

本版新增两项比赛功能：`S` 只停止车轮并暂停自动流程，保持前刷当前状态；`Z` 单独切换前刷停止/正转，不改变车轮和 Greedy 状态。OpenMV `$W` 蓝墙信息只用于 `V` 状态诊断，不再触发避障。

比赛前 240 秒内，在 `NAVIGATE / FINAL_ALIGN / COLLECT / PATROL` 正向行驶时，程序按左右编码器分别累计行程；若连续 3 秒两个车轮各自前进均不足 10 mm，则进入 `COLLISION_RECOVER`：停车、双轮倒退 50 mm、左轮后退且右轮前进原地逆时针转 110°，随后清除旧目标并重新进入 Greedy 扫描。倒退或转向编码器在安全时间内不能达到目标时，程序会暂停自动流程，避免盲动。

快速操作：摆好车辆并上电，保持静止直到收到 `IMU START ZERO LOCKED 10/10`，比赛开始时发送 `C` 或 `Q`。`V` 查询状态，`S` 只停轮，`Z` 单独开/停前刷，`F/B/L/R` 可人工脱困，脱困后再次发 `C` 或 `Q` 继续自动收集。计时不会因人工接管而重置。240 秒时程序强制进入黑区返回卸货；300 秒时停止全部执行器。

本包是完整 STM32CubeIDE 源工程，不包含预编译固件。请在 STM32CubeIDE 中执行 Clean Project、Build Project 后再通过 ST-Link 烧录。
