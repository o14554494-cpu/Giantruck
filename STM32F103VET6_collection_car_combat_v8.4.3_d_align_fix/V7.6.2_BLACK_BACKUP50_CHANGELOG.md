# v7.6.2 黑区转向前 50 mm 倒车

基线：`STM32F103VET6_collection_car_combat_v7.6.2_ccw90_continue`

## 本版唯一功能变更

当黑色卸货区域覆盖率达到原有阈值（40%，并保持原有连续确认帧要求）时，卸货状态机不再立即进入 180° 转向，而是按以下顺序执行：

```text
黑色区域确认
  → UNLOAD_BACKUP_50：两轮编码器闭环后退 50 mm
  → UNLOAD_TURN_180：原有慢速、编码器闭环 180° 原地转向
  → UNLOAD_REVERSE：原有 250 mm/后方超声判断
  → 原有舵机开舱门、抖动车体卸货
```

## 参数

- `BLACK_PRE_TURN_BACKUP_PERCENT`：沿用 `BLACK_REVERSE_PERCENT`，当前为 18%。
- `BLACK_PRE_TURN_BACKUP_DISTANCE_MM`：50.0 mm。
- `BLACK_PRE_TURN_BACKUP_TIMEOUT_MS`：2500 ms。若编码器在规定时间内没有同时累计到 50 mm，车辆停止并发送故障提示，不会盲目进入转向。

新增的 50 mm 计数器只在 `UNLOAD_BACKUP_50` 状态累加，并且只接受带正确反向符号的左右轮行程；它与 180° 转向角度计数、180° 后的卸货倒车计数相互独立。

## 未改变的内容

- 未修改 OpenMV 视觉代码、黑色区域阈值、3%/40%确认策略。
- 未修改初始对齐、后墙倒车、逆时针 90°、黑区跟随、左墙碰撞恢复、180°转向控制、后续卸货倒车或舵机逻辑。
- 未修改 UART、引脚、编码器符号、PID 和其他模式。

## 验证

- `make -C tests clean all`：通过全部主机回归、刷子反馈、JY901 和采样测试。
- `clang -fsyntax-only ... Core/Src/main.c`：通过 STM32 HAL 头文件语法检查。
- `python3 -m py_compile OpenMV/main.py`：通过。

本版仍需在实车上确认 50 mm 的编码器标定、后退方向和车体实际安全间距；若任一车轮编码器失效，超时保护会停车并提示检查编码器。
