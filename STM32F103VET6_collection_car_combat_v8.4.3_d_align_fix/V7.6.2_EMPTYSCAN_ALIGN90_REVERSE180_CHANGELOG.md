# V7.6.2 空扫描对齐/90°/倒车顺序修订

## 本次修改

- Greedy 的 6×60°扫描没有发现物块时，先停车并对齐上电时保存的 IMU 初始 0°。
- 对齐完成后，使用双轮差速和 IMU PID 完整逆时针旋转 90°。
- 90°确认完成后，才进入后方超声倒车流程。
- 后墙超声停车阈值由 200 mm 调整为 180 mm，仍需连续 3 个新鲜采样确认。
- 到达后墙后，沿旋转后的航向慢速前进寻找黑色区域；黑色区域识别、80 mm预退、CW60、300 mm/120 mm/10 s卸货逻辑保持不变。

## 新流程

```text
EMPTY_SCAN
  -> ALIGN_INITIAL (IMU 0°)
  -> TURN_CCW90 (IMU PID)
  -> REVERSE_WALL (rear sonar <=180 mm, 3 samples)
  -> SEARCH_FORWARD_BLACK
  -> BLACK_APPROACH / UNLOAD
```

## 主要蓝牙反馈

```text
IMU 0 DEG LOCKED: IMU PID CCW 90 START BEFORE REVERSE
IMU PID CCW 90 LOCKED: REVERSE TO REAR WALL 180MM
REAR WALL 180MM CONFIRMED: SLOW FORWARD SEARCH BLACK; LEFT-WALL RECOVERY ARMED
```
