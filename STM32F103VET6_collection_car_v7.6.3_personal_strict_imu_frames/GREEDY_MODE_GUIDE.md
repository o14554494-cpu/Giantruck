# Q 看一个、抓一个模式

本版速度：Q 搜索约 75% PWM，直行跟随和盲区进料约 73% PWM。专用逻辑参数在 greedy_collection.h：GREEDY_SCAN_SPEED_PERCENT=38，GREEDY_FORWARD_SPEED_PERCENT=32，通过 60% 最低 PWM 映射得到上述输出。转向时两轮差速；最终对准阶段仍使用 GREEDY_ALIGN_SPEED_PERCENT=20 降速，并限制差速范围，避免车辆绕到物块边缘。跟随启动仍有 80% / 200 ms 补偿。回仓和解卡沿用原速度。

跟随目标横向偏移时，两轮都保持前进，只改变左右速度；ACTION=DIFF_LEFT/DIFF_RIGHT 表示受限差速修正。取消 REACQUIRE：空帧/目标不可见时停轮并显示 LOST，距最后一次看到目标达到 600 ms 后重新扫描，不再额外等待 1.5 s；视觉失联保护仍保留。

当前固件标记：`FW=v6.1+GREEDY_START_UR`。Q使用当前摄像头观测跟随一个目标，不维护多物块全局距离列表，不调用路线优化器，也不再按收集动作计数决定卸货。分段扫描、Coverage和卸货调头有IMU航向辅助；物块对准仍使用OpenMV，进料距离仍使用车轮编码器。

## 使用

重新导入完整工程，Refresh、Clean、Build，确认新增的 `Core/Src/greedy_local.c` 参与编译，再烧录 `collection_car_combat_v6_1.elf`。Core 已在 Debug/Release 源码目录中，无需改引脚、CubeMX 或视觉串口协议。

将车放在配置的起始位置和朝向，上电发一次 Q。Q 重置本轮任务和里程计，不能循环连发。正常只需要 Q；V 为查询，M/P 返回当前单目标信息，不再列出历史路线。前刷 A→PB12、B→PB15；默认反馈 SIGN=-1，保持上一版接线。

## 看一个、抓一个

1. 无目标时先停车观察300ms，再转约60°后停车观察，一轮6次；中途有目标立即退出扫描。角度优先使用新鲜JY901S航向，IMU过期则退回带符号轮程；单步超过3000ms未到角度就停止Q并报告SCAN TIMEOUT，此时检查IMU正负方向/数据以及轮编码器。只有搜索阶段使用两轮相反方向原地转动。
2. 从当前有效帧中选择相对直线距离最近的红/黄目标，接受单帧、无质量最低门槛，前向距离仍限制在 60～2500 mm。
3. 锁定一个目标，根据颜色、相对方位和距离连续性更新它，不因出现更近的新物块立即换目标。软件只保留一个目标结构，不存储其全局坐标。
4. 目标靠右：左轮快、右轮慢；目标靠左则相反。两轮始终保持正向分量，最大差速由 GREEDY_STEER_MAX_PERCENT=20 限制；进入 ALIGN 后基准降为 20、最大差速为 18。这样既能转向又能继续接近，不再用单轮停转绕目标。实际方向取决于左右电机接线正确。
5. 进入近距 220 mm 内、横向偏差不超过 25 mm，开始直行进料。此时目标轮程固定为“视觉剩余距离 + 相机前向偏移（默认 0）+ 150 mm”，左右轮净前进轮程均达到目标才认为本次动作完成。
6. 进料开始后即使收到 RAW=0 的有效空帧也继续；4 秒未走够则停车退出任务、禁用自动解卡，前刷仍正转。车轮反向或单轮不动不能完成进料。
7. 完成后丢弃本次目标，停车并至少等待 400 ms 后的新观测，再找下一个。旧帧不会直接触发下一次收集。
8. 每次动作完成后重新扫描；一轮扫描无目标就进入Coverage。Coverage途中发现物块则拾取后重新扫描；完整Coverage仍无目标才前往右上卸货区，倒车并驱动后舵机卸货。再次Q会重设任务位姿。

模块中的“锁定”是短时观测关联，不是已确认的物理物块身份；两个同色物块重叠或快速交错时仍可能匹配错。每帧只选择一个最佳匹配，避免把多个色块累计成几十个地图记录。

## 丢失、障碍和保护

- 接近阶段一旦当前帧没有匹配目标就停轮，不继续向历史坐标行驶；最近有效目标超过 600 ms 未更新后继续保持停车，累计 1.5 s 仍未恢复才释放锁定并重新扫描。
- 锁定后跟随 12 秒仍未完成接近则停车重扫，防止无限追逐一个错误观测。
- Q 普通接近阶段，前超声有效距离不超过 180 mm 时只停车，显示 OBSTACLE；不按错误的全局位姿触发后退/朝场中心转弯。末端 ALIGN/COLLECT 沿用近距进料设计，不把物块本身作为超声避障触发。
- 视觉串口完全失联超过 1.2 秒仍停轮，不把串口失联当成正常盲区；恢复后重扫，不恢复已打断进料。
- Q 继续自动启用前刷堵转监测。NO_FEEDBACK 指前刷反馈未验证，和 RAW=0 无关；仍会停轮停刷、进入 HOLD。这次修改不代表已解决硬件无反馈。
- 正常解卡结束保留收集计数和里程计，清除当前目标，等待新视觉后搜索。HOLD 每 2 秒回 JAM_HOLD ALIVE，V 可查询。
- S 停任务并禁用自动解卡，普通运行时保持前刷正转；H 停轮停刷。故障排除后 K 恢复刷子，等待恢复完成，再回配置起点/朝向发 Q。
- Q 跟随不再使用全局场地坐标过滤目标，场外彩色干扰需由视觉 ROI、场地标志等限制。回仓仍使用原里程计和场地参数，需要标定；“能跟随物块”不表示回仓定位已经准确。

## 蓝牙输出

Q 周期状态最多约每秒一组，不再每次把所有候选逐行打印。V 可强制查看完整当前帧；M/P 只看锁定对象。发送仍使用现有串口发送方式，降低输出频率不等于已实现异步串口。

```text
MODE=GREEDY: NO COUNT LIMIT; SCAN EMPTY -> COVERAGE; COVERAGE EMPTY -> UNLOAD
GREEDY LIST=1 CURRENT=1 STATE=NAVIGATE SCAN=OFF ACTION=FOLLOW STEP=0/6 NAV=IMU PAYLOAD=NO
VISION OK SEQ=100 RAW=3 MAP=1 AGE=40 RXERR=0 MODE=GREEDY DBG=OFF PICK=-1
LOCAL LOCK=1 VISIBLE=1 C=1 X=30 Y=600 AGE=40; NO GLOBAL LIST
GREEDY PICKUP START: GOAL=350 EXTRA=150 mm; WHEEL_DISTANCE
GREEDY PICKUP L=120 R=118 GOAL=350 mm ELAPSED=600 ASSUMED=1
GREEDY PICKUP ACTION COMPLETE: RESCAN
```

- RAW：最新帧物块数，可大于 1。
- MAP/LIST：兼容旧字段，现在只表示锁定目标是否可见/新鲜，最多为 1；不再表示累计地图大小。
- CURRENT：0=无当前任务目标，1=单目标锁定标志，不是物块编号。
- LOCAL X/Y：相机相对横向/前向毫米，X 正数为右侧。
- ACTION：SEARCH 搜索；FOLLOW 直行；DIFF_LEFT/DIFF_RIGHT 双轮正向差速；LOST 目标丢失；OBSTACLE 超声停车；FEED 盲区进料；DONE 完成收集动作。
- SCAN：OBSERVE 停车观察、TURN 搜索短转、OFF 已退出搜索。
- PAYLOAD：仅表示本轮是否至少执行过一次进料动作，不是物块数量，也没有入仓传感器确认。车轮打滑或物块被推开时，PAYLOAD仍可能为YES。

周期输出受采样影响，可能漏掉短暂状态；锁定刚建立的一个控制周期内 ACTION 可能尚未切到 FOLLOW。进料期间保留承诺的目标，MAP 可在最后观测变旧后变为 0，进料不因此中断。

## 文件和参数

| 文件 | 作用 |
|---|---|
| Core/Src/greedy_local.c | 只保存一个相机相对目标；首次选最近，后续连续匹配 |
| Core/Inc/greedy_local.h | 丢失 600 ms、跟随上限 12000 ms、收集后停顿 400 ms、状态周期 1000 ms |
| Core/Src/main.c | Q 状态机、前进差速、进料、蓝牙、扫描无目标后Coverage及最终返仓 |
| Core/Inc/greedy_collection.h | 搜索 60°×6 / 3000 ms 失败时限 / 300 ms 观察；进料触发 220 mm、额外 150 mm、超时 4000 ms |
| Core/Src/greedy_collection.c | 旧全局列表和计数 API 留作历史兼容；当前 Q 不写入、不查询，也不以其决定返仓 |
| Core/Inc/brush_feedback_config.h | 前刷反馈方向、堵转判据、反转及 HOLD 提示参数 |
| Core/Inc/mission_extension.h | 回仓起点、场地、卸货位置，仍须按实车配置 |

宿主回归已验证：多目标只锁一个、同色/异色干扰不直接抢占、全局位姿大幅跳动仍按相机输出前进方向、MAP 不累积、丢失/跟随超时重扫、盲区行程、停止/解卡/失联中断、连续12次动作不提前卸货、Coverage结束返仓及原A/C/D行为。HAL头文件下语法检查通过；未做ARM链接构建或实车验证。
