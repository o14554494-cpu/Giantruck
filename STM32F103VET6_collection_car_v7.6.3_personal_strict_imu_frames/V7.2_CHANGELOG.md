# v7.2：最新视觉浮点协议与直接回墙卸货

> 本文件记录 v7.2 历史实现。当前工程为 v7.3，40% 到达门限、慢速接近和左墙碰撞恢复见 `V7.3_CHANGELOG.md`。

## 视觉对接

- `OpenMV/main.py` 已切换为用户提供的 `visual_latest_20260908.py`，两者内容及 SHA256 完全一致。
- 新视觉发送：`$B,seen,cx,cy,w,h,area,coverage*CS`。
- `cx/cy` 为 `-1.000..1.000` 浮点文本，`coverage` 为百分比浮点文本。
- STM32 不启用浮点 `sscanf`，而是在 `vision_protocol.c` 中直接转成定点：
  `center_x_milli/center_y_milli` 为坐标乘 1000，`coverage_x10` 为百分比乘 10。
- 非法字段、越界坐标、越界占比仍会增加协议错误计数。

## 新卸货流程

Greedy 六次 60° 物块扫描均为空，或蓝牙发送 `D` 后，直接执行：

1. IMU PID 对齐任务初始 `0°`；不再先连续旋转搜索黑色。
2. 保持 `0°` 低速倒车，后方超声连续 3 次 `<=150 mm` 后停车。
3. IMU PID 逆时针旋转 90°。
4. IMU 保持直线向前搜索黑色区域。
5. 黑色占比连续 3 包达到 `3.0%` 后，进入视觉引导前进。
6. 根据黑区中心横坐标差速修正，继续向黑区前进。
7. 黑色占比连续 3 包达到 `50.0%` 后停车，以编码器完成 180° 转向。
8. 倒车 250 mm，或后方超声连续 2 次 `<=120 mm`，进入卸货。
9. 后舱门舵机 `90° -> 0° -> 180°`，随后车体前后抖动；5 秒后完成。

## 控制门限

```c
BLACK_VISION_START_X10   30U   /* 3.0% */
BLACK_VISION_ARRIVE_X10 500U   /* 50.0% */
BLACK_VISION_CONFIRM_PACKETS 3U
```

`COVER_X10=30` 表示 3.0%，`COVER_X10=500` 表示 50.0%。

## 蓝牙入口

- `Q`：Greedy 收集；最终物块扫描为空后自动进入上述卸货流程。
- `D`：跳过物块收集，直接从“IMU 对齐初始 0°”开始测试卸货。
- `V`：查看当前模式、IMU、黑区占比和状态。
- `S`：立即停止并退出自动状态。

## 验证

- OpenMV 两份脚本均通过 Python 语法检查。
- C 主机测试以 `-Wall -Wextra -Werror` 编译通过。
- 协议测试验证 `-0.250/0.125/30.5%` 可正确转换为 `-250/125/305`。
- 控制回归验证 2.9% 不触发、3.0% 连续三包触发跟随、50.0% 连续三包触发转向。
- 编码器 180°、倒车 250 mm、后舱门舵机与车体抖动流程通过回归测试。
