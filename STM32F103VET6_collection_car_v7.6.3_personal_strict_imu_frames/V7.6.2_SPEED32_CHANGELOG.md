# v7.6.2 Greedy 前进速度修订

基线：`STM32F103VET6_collection_car_combat_v7.6.2_imu_turns_timeout200_backup80_fallback10s`

## 修改内容

- `GREEDY_FORWARD_SPEED_PERCENT`：`26 → 32`。
- 该参数用于 Greedy 普通目标跟随和盲区进料，经过现有 60% 最低 PWM 映射后约为 `70% → 73%` 实际轮 PWM。
- `GREEDY_ALIGN_SPEED_PERCENT=20` 保持不变，最终对准仍低速运行，减少物块偏到收集口边缘的风险。
- 扫描、黑区搜索、IMU 转向、卸货倒车、手动控制和其他模式未修改。

## 验证

- `make -C tests clean all`：通过；
- STM32 `main.c` 语法检查：通过；
- OpenMV Python 语法检查：通过。

首次实车测试建议观察物块接近时是否出现冲过目标、边缘漏收或电机过热；如有问题，可将该参数回调到 30 或 28。
