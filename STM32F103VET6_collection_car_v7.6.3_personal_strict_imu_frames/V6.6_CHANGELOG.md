# v6.6 IMU扫描归零与倒车平滑修订

启动标记：`FW=v6.6+IMU_SCAN_ZERO_REVERSE_SMOOTH`

## 修改内容

1. Greedy初始扫描由恒定轮速/编码器角度判断改为JY901航向PID。
2. 六个扫描目标统一锚定到扫描起始航向：60、120、180、240、300、0度，避免每一步打滑误差累计。
3. 每一步必须在目标±2度内稳定180 ms，随后停车观察300 ms；第六步重新对准扫描零点。
4. 删除Greedy扫描的编码器角度降级。IMU失联时停车，3秒超时后安全退出并通过蓝牙说明原因。
5. Coverage的六段扫描同样改成每圈统一零点，最后回到本圈起始航向，并加入180 ms稳定确认。
6. 倒车航向环KD原本已为0。本版通过降低KP/KI、扩大死区、减小最大左右差速、增强低通和减慢修正变化来抑制低速左右抖动。

## 当前参数

- Greedy扫描PID：KP=26、KI=0.35、KD=0.35，逻辑输出8～38。
- 扫描角度容差：约2度；稳定确认：180 ms；视觉观察：300 ms；单步超时：3000 ms。
- Coverage倒车PI：KP=8、KI=0.05、KD=0；基础逻辑速度12；最大差速修正3；等速死区约3度。
- 驱动层仍把非零逻辑输出映射到至少60%物理PWM，因此逻辑输出8并不代表8%物理占空比。

## 实车验证

1. 上电确认蓝牙首行包含本版启动标记。
2. 小车放在地面标线0度方向，发送Q。
3. 应依次看到六条 `STEP=n/6 LOCKED`，每次转动后停车观察；第六条包含 `ZERO_RESTORED`，车头应回到0度标线附近。
4. 转动期间发送V时，`NAV=IMU_PID`表示IMU有效；`NAV=WAIT_IMU`表示正在等待IMU，车轮不得继续转动。
5. 使用D检查倒车。约3度以内左右轮应保持等速倒车，不应因1～2度噪声来回换边。

主机回归测试：`cd tests && make test`，本版全部通过。实车PWM、轮胎附着和负载仍需落地验证。
