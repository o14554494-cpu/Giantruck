# v7.6.2 卸货预倒车 80 mm / 10 s 兜底修订

基线：`STM32F103VET6_collection_car_combat_v7.6.2_imu_turns_timeout200`

## 修改内容

- 黑区达到 40% 后，180° IMU 转向前的编码器预倒车从 `50 mm` 改为 `80 mm`；预倒车状态和蓝牙提示同步改为 `BACKUP_80` / `BACKUP 80MM`。
- 180°转向完成后的卸货倒车保留两种正常完成条件：
  - 两侧编码器都累计倒车 `250 mm`；或
  - 后方超声连续 2 个有效采样 `≤120 mm`。
- 新增第三种正常卸货条件：进入 `AUTO_UNLOAD_REVERSE` 后满 `10 s`，即使编码器或超声没有触发，也直接启动舱门舵机和抖动卸货。
- 删除该阶段“超时后停车并报故障”的分支。10 s 是卸货兜底，不是 `TIMEOUT` 故障。

## 蓝牙反馈

```text
BLACK >=40% CONFIRMED: BACKUP 80MM BEFORE 180
PRE-TURN BACKUP 80MM COMPLETE: IMU PID 180 START
UNLOAD REVERSE 250MM COMPLETE: HATCH/ SHAKE START
UNLOAD REAR SONAR 120MM: HATCH/ SHAKE START
UNLOAD REVERSE 10S FALLBACK: HATCH/ SHAKE START
```

## 验证

- `make -C tests clean all`：通过，包含 80 mm 预倒车和 10 s 兜底测试；
- STM32 `main.c` 语法检查：通过；
- OpenMV Python 语法检查：通过。

首次实车测试请确认后退方向和后墙距离；若后方超声、编码器均失效，车辆仍会在 10 s 后卸货，因此不要把 10 s 兜底当成碰撞保护。
