# 个人赛周期IMU校准说明

## 两套参考互不覆盖

本版没有每20秒直接重写“比赛初始0°”。那样会把小车当时的任意朝向错误地定义为起点方向，最终卸货反而会找错方向。

- **初始参考**：上电时小车静止采集连续10帧，保存整场个人赛的初始0°，只给最终返回和卸货转向使用。
- **短期参考**：给下一段直线/倒车的航向PID使用，可以周期刷新，用于减小长时间震动和传感器短期偏移对直线行驶的影响。

## 自动周期校准流程

1. 短期参考年龄达到20秒时，只把校准标记为“到期”；
2. 如果正在跟随、转向、盲区补偿拾取或解卡，继续完成当前动作，不会突然停车；
3. 到达下一次6×60°扫描的起始停车窗口后，保持车轮停止300 ms；
4. 接收6个不同且新鲜的JY901S航向帧；
5. 六帧之间变化必须在约1.5°以内，否则认为车体仍在移动，重新累计；
6. 成功后仅更新短期参考，清除直线PID历史项，然后重新开始扫描；
7. 2秒内无法得到稳定六帧时，保留上一次有效短期参考并继续扫描，不会把错误数据写入控制器。

此外，每次完成拾取和每次完成自动解卡后，本来就会进入相同的6帧短期刷新流程，因此高碰撞、高震动情况下不必等满20秒。

## 蓝牙可见反馈

周期到期时：

```text
IMU PERIODIC REFRESH DUE: AGE>=20S; STOP 300MS + 6 STABLE FRAMES
IMU LOCAL REFRESH: STOP 300MS, THEN 6 STABLE FRAMES; START ZERO PRESERVED
```

成功时：

```text
IMU LOCAL REFRESH LOCKED 6/6: START ZERO UNCHANGED; RESCAN
```

失败时：

```text
IMU LOCAL REFRESH TIMEOUT: KEEP OLD LOCAL REF; RESCAN
```

发送 `V` 可查看：

```text
IMU_DUAL START_RAW=... LOCAL=LOCKED/REFRESH LOCAL_RAW=... SAMPLE=.../6 LOCAL_AGE=... ms
```

其中 `START_RAW` 应在整场任务中保持不变，`LOCAL_RAW`允许在安全刷新后变化。

## 能解决与不能解决的问题

可改善：震动后下一段直线偏航、PID沿用旧误差、解卡或拾取后短期航向偏置。

不能单独解决：磁场干扰造成的绝对航向长期漂移、IMU安装松动、左右轮编码器丢脉冲、轮胎打滑。若 `START_RAW`对应的物理方向长期明显漂移，需要检查磁校准、电机/大电流导线距离和安装刚性，不能通过反复软件置零伪装修复。
